## Objective

The objective of this investigation was to analyze a Windows successful logon event collected from the monitored Windows 10 endpoint and understand how authentication activity is detected, processed, and mapped by Wazuh.

---

## Environment

The event was generated and analyzed within the Wazuh SOC Home Lab environment.

- Wazuh SOC Server: Ubuntu Server
- SIEM Platform: Wazuh
- Endpoint: Windows 10 VM
- Wazuh Agent: Active
- Endpoint Name: MSEDGEWIN10
- Agent ID: 002

## Investigation Process

The investigation began by filtering Wazuh Discover results for the monitored Windows endpoint.

The following filter was used:

agent.id:002

The Windows authentication events were then reviewed to identify successful and failed logon activity.

A successful authentication event with Windows Event ID 4624 was identified.

The event details were expanded and the following information was examined:

- Target username
- Target domain
- Logon type
- Authentication package
- Source IP address
- Workstation name
- Process name
- Event timestamp
- Wazuh rule information
- MITRE ATT&CK mapping

---

## Key Findings

The analyzed event showed that an account was successfully authenticated on the Windows endpoint.

The event was recorded in the Windows Security event channel and forwarded to the Wazuh SOC platform by the Wazuh agent.

Important observations included:

- Windows Event ID 4624 confirmed successful authentication.
- The event was generated by Microsoft-Windows-Security-Auditing.
- The endpoint was successfully monitored by Wazuh Agent ID 002.
- The authentication package used was Negotiate.
- The logon type was 2.
- The event was classified as AUDIT_SUCCESS.
- Wazuh generated Rule ID 60118 for the event.
- The Wazuh rule severity level was 3.

---

## Logon Type Analysis

The event contained the following value:

Logon Type: 2

Logon Type 2 represents an interactive logon.

This indicates that the authentication activity was associated with a user logging on interactively to the Windows system.

---

## Wazuh Rule Analysis

The event was processed by Wazuh using the following rule:

| Field | Value |
|---|---|
| Rule ID | 60118 |
| Rule Description | Windows Workstation Logon Success |
| Rule Level | 3 |
| Rule Group | windows, windows_security, authentication_success |

The rule classified the event as a successful Windows workstation authentication event.

---

## MITRE ATT&CK Mapping

Wazuh automatically mapped the event to the following MITRE ATT&CK technique.

| MITRE Field | Value |
|---|---|
| Technique | Valid Accounts |
| Technique ID | T1078 |

The event was associated with the following MITRE ATT&CK tactics:

- Initial Access
- Persistence
- Privilege Escalation
- Defense Evasion

### Important Context

The MITRE ATT&CK mapping does not automatically mean that the observed successful logon was malicious.

The current event was analyzed as expected authentication activity within the lab environment.

The Valid Accounts technique is relevant because legitimate credentials can potentially be abused by attackers to gain access to systems.

Therefore, the MITRE mapping provides investigation context rather than confirming malicious activity.

## Investigation Conclusion

The analyzed Windows Event ID 4624 represented a successful interactive logon on the monitored Windows 10 endpoint.

The Wazuh agent successfully collected the Windows Security event and forwarded it to the Wazuh SOC platform.

The event was processed using Wazuh Rule ID 60118 and assigned a severity level of 3.

Wazuh also mapped the event to MITRE ATT&CK Technique T1078, Valid Accounts. However, after reviewing the event context, the activity was determined to be expected and benign authentication activity within the controlled lab environment.

No suspicious activity was identified during this investigation.
